Central de ajuda.

Respostas para começar e cuidar da sua instalação do Termux Nexus.

Como instalar?

Abra o Termux e execute os comandos abaixo:

pkg update -y
pkg install -y git python
git clone https://github.com/EchoX10/termux-nexus.git
cd termux-nexus
bash install.sh

Depois, execute nexus para abrir a central.

Como atualizar?

cd ~/termux-nexus
git pull origin main
bash install.sh

Se você instalou o projeto em outra pasta, entre nela antes de atualizar.

O comando nexus não funciona

Confira se o instalador terminou sem erros. Feche e abra uma nova sessão do Termux. Se continuar, execute novamente bash install.sh dentro da pasta do projeto.

Onde pedir ajuda?

Consulte a documentação e abra uma issue no repositório com a mensagem de erro completa. Nunca publique tokens, senhas ou outros segredos.
